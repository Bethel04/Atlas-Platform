# PULL REQUEST LAB 

## What is a Pull Request?
A pull request is a request to merge changes from one branch into another branch, while giving people an opportunity to review those changes first.

## why use a pull request
we use a pull resquest for team collaboration of team projects, so when a pull request is extablish the leader review it and then 
check if the code it okay.

## pull request workflow 
first create a feature  branch 
switch to the feature branch
make changes 
stage the changes with git add
commit the changes with git commit
then push the feature branch to github
open a pull request
review the changes 
merge the pull request
