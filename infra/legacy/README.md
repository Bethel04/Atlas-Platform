# Legacy archive for Atlas Platform

This folder stores legacy Linux lab materials as a historical record.

## Purpose

- Preserve older Linux lab scripts and supporting screenshots.
- Keep a documented archive separate from current platform source and documentation.
- Provide a clear home for legacy artifacts when migrating them into the monorepo.

## Current legacy archive structure

- `scripts/` — legacy shell scripts and automation.
- `screenshots/` — legacy screenshots, diagrams, or visual references.

## Usage

1. Place legacy shell scripts under `infra/legacy/scripts/`.
2. Place legacy images under `infra/legacy/screenshots/`.
3. Update this README with a short description of each migrated artifact.

## Historical note

At the time of this commit, no separate Linux lab scripts or screenshots were found outside this package. The folder remains in place to support future addition of historical assets and to document the legacy archive.
